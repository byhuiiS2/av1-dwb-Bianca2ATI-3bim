# API Hello Kitty

API REST de personagens da Hello Kitty.

## Como executar

```bash
npm install
npm start
```

A API fica disponível em `http://localhost:3000`.

A documentação Swagger está em `http://localhost:3000/api-docs`.

## Rotas

- `GET /personagens`
- `GET /usuarios`
- `POST /upload` com o arquivo no campo `arquivo`
